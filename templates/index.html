📁 XML File Merger

Merge two XML files by selecting a time cutoff.
Elements from File 1 that occur before the selected time and elements from File 2 that occur at or after the selected time will be combined into a single merged XML file.

Elements with timestamps before the cutoff time will be taken from this file.

Elements with timestamps at or after the cutoff time will be taken from this file.

The point in time that divides the two XML files. Timestamps before this value come from File 1; timestamps at or after come from File 2.

How it works

  1. Upload two XML files that contain child elements with time values.
  2. Each child element must have a time value in one of these forms:
    • An attribute named time, timestamp, datetime, or date.
    • A child element with one of those tag names.
  3. Select the cutoff date and time.
  4. Click Merge & Download to receive the merged XML.

Supported date/time formats

  • 2024-01-15T14:30:00 (ISO 8601)
  • 2024-01-15T14:30:00.000 (ISO 8601 with milliseconds)
  • 2024-01-15 14:30:00
  • 2024-01-15 14:30
  • 2024-01-15T14:30
  • 2024-01-15
  • 14:30:00
  • 14:30

Example XML structure

<events>
  <event time="2024-01-15T08:00:00">Morning briefing</event>
  <event time="2024-01-15T12:00:00">Lunch meeting</event>
  <event time="2024-01-15T18:00:00">Evening debrief</event>
</events>
